## 🎯 Objetivo

O objetivo desta atividade foi **reproduzir fielmente um layout** desenvolvido no **Figma**, aplicando os conceitos de **HTML, CSS e boas práticas de desenvolvimento front-end**.

## 🖼️ Layout de Referência

O design original foi fornecido no Figma e serviu como guia para a construção da interface.

* **Ferramenta de design**: [Figma](https://figma.com)
* **Tarefa**: recriar a estrutura e o estilo o mais próximo possível do modelo proposto.

## 🛠️ Tecnologias Utilizadas

* **HTML5** → Estrutura semântica da página
* **CSS3** → Estilização (cores, tipografia, espaçamento, responsividade)
